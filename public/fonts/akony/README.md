# AKONY — куда положить файл

В репозитории **нет** лицензионного файла AKONY, поэтому шрифт сейчас не
подключён: дисплейный текст рендерится первым доступным запасным вариантом
(`Alumni Sans` для заголовков, `Roboto Condensed` для интерфейсных подписей).
Вёрстка к этому готова — подключение сводится к двум шагам.

## Шаг 1. Положить файл

```
public/fonts/akony/akony-variable.woff2
```

Нужен вариативный WOFF2 с диапазоном насыщенностей 400–900 **и кириллицей**.
Если лицензия даёт только статические начертания, положите их рядом
(`akony-400.woff2`, `akony-700.woff2`, `akony-900.woff2`) и раскройте в
`src/index.css` соответствующий вариант блока `@font-face`.

## Шаг 2. Раскомментировать `@font-face`

В `src/index.css` найдите блок `AKONY` и снимите комментарий. Токены
`--font-display` и `--font-ui` уже начинаются с `"AKONY"`, поэтому больше
ничего менять не нужно.

## Обязательная проверка кириллицы

AKONY распространяется в нескольких сборках, и латинская версия **не содержит
кириллицы**. Если подключить такую сборку, браузер возьмёт кириллические буквы
из запасного шрифта, и в одном слове окажутся глифы двух гарнитур — «СИГНАЛ ИЗ»
латиницей одной формы, кириллицей другой.

Проверьте покрытие до подключения:

```bash
# требуется fonttools: pip install fonttools brotli
python3 - <<'PY'
from fontTools.ttLib import TTFont
f = TTFont("public/fonts/akony/akony-variable.woff2")
cmap = set(f.getBestCmap())
probe = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"
missing = [c for c in probe if ord(c) not in cmap]
print("отсутствуют:", "".join(missing) if missing else "нет — кириллица полная")
PY
```

Если хоть один символ отсутствует — файл не подходит, нужна сборка AKONY
с кириллическим покрытием. Не подключайте её частично.
